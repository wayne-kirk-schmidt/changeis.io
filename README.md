# changeis.io

Primary website for ChangeIS — Principal Architecture & Integration practice.

**Live site:** https://changeis.io

## Stack
- Static HTML/CSS/JS — no build step required
- Hosted on GitHub Pages
- Custom domain via GoDaddy DNS

## Deploy
1. Push to `main` branch
2. GitHub Pages serves automatically
3. Custom domain configured via `CNAME` file

## Structure
- `index.html` — main site
- `CNAME` — GitHub Pages custom domain config
